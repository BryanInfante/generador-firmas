# Generador de Firmas Corporativas Littus Group

Sitio estático para generar firmas HTML compatibles con Outlook.

## Estructura

```txt
littus-signature-generator/
├── index.html
└── assets/
    ├── css/
    │   └── styles.css
    └── js/
        └── app.js
```

## Uso

1. Abrir `index.html`.
2. Completar los datos.
3. Copiar la firma para Outlook.
4. Pegarla en la configuración de firmas de Outlook.

No requiere backend ni base de datos.
